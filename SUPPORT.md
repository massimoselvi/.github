# Support

The repositories owned by [@massimoselvi](https://github.com/massimoselvi) are personal projects. Support is best effort and has no guaranteed response time.

## Where to get help

| Need | Channel |
| --- | --- |
| You found a bug | Open an issue with the **Bug report** form |
| You want a new feature or a change | Open an issue with the **Feature request** form |
| You have a question about usage | Use GitHub Discussions if the repository enables them. If not, open an issue with the **Question** form |
| You found an accessibility barrier | Follow [ACCESSIBILITY.md](ACCESSIBILITY.md) |
| You found a security problem | Follow [SECURITY.md](SECURITY.md). Do not open a public issue |
| You want to report unacceptable behavior | Follow the enforcement section of the [Code of Conduct](CODE_OF_CONDUCT.md) |

## Before you ask

- Search the open and closed issues.
- Read the README of the repository.
- Include the version or commit, your environment, and the exact error text.

## Forks

Some repositories are forks of third-party projects. For a fork, report problems to the upstream project.
